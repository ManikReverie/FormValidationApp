# Form Validation App

## Project Overview
A simple Android app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 21). It demonstrates client-side input validation for a registration form.

## Technologies Used
- Kotlin
- XML Layouts
- Android Studio

## Features
- Input fields for Name, Email, Phone, and Password
- Validation for empty fields, email format, password length, and phone number length
- Toast messages for validation errors and success

## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.

## Outcome
The application successfully validates user inputs and provides appropriate error messages before submission.
